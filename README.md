# 🎓 ED-Tech Website

A multi-page ED-Tech website for **Coding Ninjas**, built with HTML. It is a learning-platform website where students can explore courses, register or log in, and contact the team, and where an admin can view the list of enrollments.

---

## 📌 About the Project

Coding Ninjas is an ed-tech platform that helps students and working professionals learn to code and upskill. This project is a front-end website for that platform. It was built to practice core HTML concepts such as page structure, links, images, video, tables, forms, and embedded maps.

---

## ✨ Features

- Homepage with About Us, Featured Courses, Why Choose Us, and Testimonials
- Courses page with four courses, each with a description, a video, and an Enroll button
- Registration form with user type and course selection
- Login form
- Contact page with email and phone links, an embedded Google Map, and a feedback form
- Admin dashboard with a table of user enrollments
- Social media links (Facebook, Instagram, X, LinkedIn) in the footer

---

## 🚀 How to Run

1. Download or clone this repository:
   ```
   git clone https://github.com/Shrii-090703/ED-Tech_Website.html.git
   ```
2. Open the folder `ED-Tech_Website.html/Multimedia/Pages.html/`
3. Double-click `Homepage.html` to open it in your browser.

No installation or setup is needed.
